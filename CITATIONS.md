# Citations and attribution

- Cho, K. et al. (2014). “Learning Phrase Representations using RNN Encoder–Decoder for Statistical Machine Translation.” *Proceedings of EMNLP 2014*. https://doi.org/10.3115/v1/D14-1179. The project uses a gated recurrent unit (GRU) network, a recurrent architecture introduced in this work.
- PyTorch contributors. *PyTorch documentation*. https://pytorch.org/docs/stable/. Framework used to implement and train the GRU classifier.
- Streamlit, Inc. *Streamlit documentation*. https://docs.streamlit.io/. Framework used for the interactive monitoring dashboard.
- The sensor readings and failure events in `synthetic_motors.csv` and those generated by `standalone_sensor_streamer.py` are synthetic demo data. They do not represent measurements from a real motor or an external dataset.
